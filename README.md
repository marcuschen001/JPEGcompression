This Jupyter Notebook is a simulation of the commonly used Joint Photographic Experts Group (JPEG) standard for the lossy compression for digital images. I have provided an example image attached but you will be able to upload and export your own images using the notebook as well.

To use this notebook, I'd recommend having OpenCV, numpy, matplotlib, scipy, and patchify installed, which can be done using pip. More details of the specifics and details is included on my [blog](https://chennrobotics.wordpress.com/2026/10/21/discussing-the-jpeg-compression-system-because-i-remembered-i-had-a-github/). Happy compressing!
